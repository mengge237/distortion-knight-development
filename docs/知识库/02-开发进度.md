## 近期完成（2026-08-15）

- **效果类合并**：21 个同构效果类合并为 6 个参数化类（GainBuffEffect / MultiStatBuffEffect / DrawCardsEffect / GainEnergyEffect / HealPlayerEffect / MaxHealthEffect），全部 99 个效果资产已通过校验脚本验证类绑定与字段符合性
- **编码统一**：全项目 UTF-8 无 BOM（修复 1 个 GB18030 + 280 个 BOM 文件），.editorconfig 防回归
- **硬编码清理**：新增 `GameIds.cs`（50 遗物 ID + 2 效果 ID + 13 资源路径常量），23 处 Resources 加载路径改用 ResourcePaths，修复剑核合成配方（"01"/"06" 死配方 → Synth 常量）
- **配置资产化**：新增 `Resources/GameConfig.asset`、`Resources/ShopConfig.asset`，可在 Inspector 调整
- **调试台重设计**：阵营遗物按阵营分区（中国特色配色）、添加时自动附带 Boss 激活器遗物、全界面中文
- **调试台文件开关 + 无敌**：正式包需 `debug_enable` 标记文件才启用调试台；战斗页新增无敌开关
- **商店改造**：模仿杀戮尖塔布局（遗物顶部/药水右上/卡牌居中/移除左下/离开右下），运行时自建缺失槽位，真实卡牌移除选择弹窗（确认后扣款），金币不足/购买成功提示，价格随金币变色

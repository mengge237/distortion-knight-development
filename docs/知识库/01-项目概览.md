# 项目概览 - Distortion Knight（扭曲骑士）

## 一句话介绍

Distortion Knight 是一款基于 Unity 的类 Slay the Spire 卡牌 Roguelike 游戏，玩家在程序化生成的地图中探索、与变异敌人战斗，通过构筑卡组逐步推进至最终 Boss。

## 核心玩法

- **地图探索**：程序化生成的多层节点地图（起点 → 普通怪/精英怪/事件/商店/宝箱/休息 → Boss）
- **卡牌战斗**：回合制战斗系统，每回合获得能量并从手牌中选择出牌（攻击/防御/技能/能力）
- **卡组构筑**：初始牌组 + 战斗奖励获取新卡，牌组在流程中逐步扩展
- **敌人 AI**：每种敌人拥有独立的 AI 行为模式，通过意图系统预告下一步行动
- **奖励系统**：击败敌人后获得金币和卡牌奖励（普通/精英/Boss 不同奖池）

## 技术栈

| 项目 | 详情 |
|------|------|
| 引擎 | Unity 2022.3.62f3c1 |
| 渲染管线 | Universal Render Pipeline (URP) |
| UI 文本 | TextMesh Pro |
| 动画插件 | DOTween (Demigiant) |
| 编程语言 | C# |
| 根命名空间 | `MutationChess` |

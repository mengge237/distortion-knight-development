## 核心系统详解

### GameManager（门面模式）

| 成员 | 类型 | 说明 |
|------|------|------|
| `mapGenerator` | MapGenerator | 地图生成器引用 |
| `playerController` | PlayerController | 玩家移动控制 |
| `playerPrefab` | GameObject | 玩家预制体 |
| `battleManager` | BattleManager | 战斗管理器引用 |
| `cameraFollow` | CameraFollowController | 相机跟随引用 |
| `mapView` | MapView | 地图可视化 |
| `commonRewardPool` / `eliteRewardPool` / `bossRewardPool` | RewardPool | 三级奖励池 |
| `OnNodeClicked(MapNode)` | 方法 | 处理节点点击，分发到战斗/事件/商店 |
| `OnNodeReached(MapNode)` | 方法 | 节点到达后的逻辑分发 |
| `OnBattleEnd(bool)` | 方法 | 战斗结束处理（胜利分支待实现） |
| `GetRandomNormalEnemy()` / `GetRandomEliteEnemy()` | 方法 | 随机选取敌人（硬编码） |

### BattleManager（战斗管理器 - 单例）

| 成员 | 类型 | 说明 |
|------|------|------|
| `isInBattle` | bool | 当前是否在战斗中 |
| `currentEnemy` | Enemy | 当前敌人实例 |
| `playerBlock` | int | 玩家当前格挡 |
| `currentIntent` | EnemyIntentType | 敌人当前意图 |
| `currentAction` | EnemyAction | 敌人当前行动数据 |
| `OnBattleEnd(bool)` | 事件 | 战斗结束事件 |
| `StartBattle(Enemy, PlayerData)` | 方法 | 启动战斗流程 |
| `PlayerAttack(int)` | 方法 | 玩家攻击（扣敌方血量 + Buff 修正） |
| `PlayerBlock(int)` | 方法 | 玩家获得格挡 |
| `ShowBattleView()` / `ShowMapView()` | 方法 | 战斗/地图视图切换 |

### HandManager（手牌管理器 - 单例）

| 成员 | 类型 | 说明 |
|------|------|------|
| `drawPile` / `handCards` / `discardPile` | List\<Card\> | 抽牌堆/手牌/弃牌堆 |
| `maxEnergy` / `currentEnergy` | int | 最大/当前能量（默认 3） |
| `cardsPerTurn` | int | 每回合抽牌数（默认 5） |
| `maxHandSize` | int | 最大手牌上限（默认 10） |
| `OnEnergyChanged` | 事件 | 能量变化事件 |
| `OnCardPlayed` | 事件 | 出牌事件 |
| `OnHandUpdated` | 事件 | 手牌更新事件 |
| `StartBattle()` / `EndBattle()` | 方法 | 战斗开始/结束初始化 |
| `DrawCards(int)` | 方法 | 抽牌（含抽牌堆空时重洗弃牌堆） |
| `PlayCard(Card)` | 方法 | 出牌（消耗能量 → 执行效果 → 弃入弃牌堆） |
| `DiscardCard(Card)` | 方法 | 弃牌 |

### PlayerDataManager（玩家数据管理器 - 单例）

| 成员 | 类型 | 说明 |
|------|------|------|
| `playerData` | PlayerData | 玩家数据实例 |
| `initialDeck` | DeckData | 初始牌组配置 |
| `runtimeDeck` | List\<Card\> | 运行时牌组 |
| `OnDataChanged` | 委托 | 数据变化通知 |
| `InitializeDeck(DeckData)` | 方法 | 从 SO 初始化牌组 |
| `AddCardToDeck(Card)` | 方法 | 向运行时牌组添加卡牌 |
| `Heal(int)` / `TakeDamage(int)` | 方法 | 治疗/受伤 |
| `AddGold(int)` / `RemoveGold(int)` | 方法 | 金币增减 |

### MapGenerator（地图生成器）

| 成员 | 类型 | 说明 |
|------|------|------|
| `rows` | int | 地图层数（默认 8） |
| `maxNodesPerRow` | int | 每层最大节点数（默认 4） |
| `horizontalSpacing` / `verticalSpacing` | float | 节点间距 |
| `extraBranches` | int | 额外分支数（默认 2） |
| `nodeBlueprints` | List\<NodeBlueprint\> | 节点蓝图列表 |
| `OnNodeReached` | 事件 | 到达节点事件 |
| `GenerateMap()` | 方法 (public) | 生成完整地图 |
| `GetFinalNode()` | 方法 | 获取 Boss 节点 |
| `BuildFullConnections()` | 方法 | 构建节点连线 |
| `EnsureAllNodesReachableFromBottom()` | 方法 | 确保所有节点可达 |

### Enemy（敌人 - 非单例，工厂创建）

| 成员 | 类型 | 说明 |
|------|------|------|
| `enemyName` | string | 敌人名称 |
| `maxHealth` / `currentHealth` | int | 生命值 |
| `enemyType` | EnemyType | Normal/Elite/Boss/Event |
| `aiPattern` | EnemyAIPattern | AI 行为模式 |
| `buffs` | List\<Buff\> | Buff 列表 |
| `delayedDamages` | List\<int\> | 延迟伤害队列 |
| `isSecondForm` | bool | 是否二阶段形态 |
| `GetNextAction()` | 方法 | 获取下一个 AI 行动 |
| `SwitchToSecondForm()` | 方法 | Boss 切换二阶段 |
| 工厂方法（13 个） | static | `CreateCorruptedSoldier()` 到 `CreateCorruptedKing()` 等 |

## ScriptableObject 配置清单

| 类名 | 用途 | 菜单路径 |
|------|------|----------|
| `DeckData` | 牌组配置 | MutationChess/Deck Data |
| `RewardPool` | 奖励池配置 | MutationChess/Reward Pool |
| `MapConfig` | 地图参数配置 | MutationChess/Map Config |
| `NodeBlueprint` | 节点蓝图（类型/颜色/预制体） | MutationChess/Node Blueprint |
| `BackgroundConfig` | 战斗背景配置 | MutationChess/Background Config |
| `EnemyLibrary` | 敌人库 | MutationChess/Enemy Library |
| `CardEffect`（子类） | 卡牌效果配置 | 各子类独立菜单 |

## 设计模式汇总

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **单例模式** | 9 个管理器类 | `public static Instance { get; private set; }` + Awake 赋值 |
| **门面模式** | GameManager | 统一调度地图/战斗/玩家/相机子系统 |
| **策略模式** | CardEffect 体系 | 抽象基类 + 19 个具体子类，通过 CombatContext 传参 |
| **工厂方法** | Enemy, CardData | Enemy 有 13 个静态工厂方法；CardData 是静态卡牌工厂 |
| **观察者模式** | 事件/委托 | BattleManager.OnBattleEnd、TurnManager 的 4 个事件、HandManager 的 3 个事件 |
| **数据驱动配置** | ScriptableObject | 配置数据与逻辑代码分离 |
| **模板方法** | CardEffect.Execute() | 抽象方法由子类实现；MapGenerator 蓝图优先级查找链 |
| **对象池/缓存** | 多处缓存 | CardData.effectCache、EnemyAIManager.patterns、MapGenerator.blueprintCache/textureCache |

## 事件系统表

| 事件源 | 事件名称 | 参数 | 监听方 |
|--------|----------|------|--------|
| MapGenerator | `OnNodeReached` | MapNode | GameManager |
| MapGenerator | `OnNodeClickedAction` | MapNode | NodeClickHandler |
| BattleManager | `OnBattleEnd` | bool (victory) | GameManager |
| TurnManager | `OnPlayerTurnStart` | 无 | HandManager 等 |
| TurnManager | `OnPlayerTurnEnd` | 无 | HandManager 等 |
| TurnManager | `OnEnemyTurnStart` | 无 | BattleManager 等 |
| TurnManager | `OnEnemyTurnEnd` | 无 | BattleManager 等 |
| HandManager | `OnEnergyChanged` | int (current) | UI 能量显示 |
| HandManager | `OnCardPlayed` | Card | 战斗日志等 |
| HandManager | `OnHandUpdated` | 无 | UI 手牌刷新 |
| PlayerDataManager | `OnDataChanged` | 无 | UI 状态栏 |

## 架构简述

Distortion Knight 采用 **GameManager 门面模式** 统一调度四大核心子系统：地图探索、卡牌战斗、玩家数据、UI 管理。各子系统内部由对应的单例管理器（BattleManager、HandManager、MapManager 等）独立运作，通过 C# 事件/委托进行跨系统通信。

核心数据使用 **ScriptableObject** 驱动（牌组、奖励池、地图配置、节点蓝图、战斗背景），卡牌效果采用 **策略模式**（CardEffect 抽象基类 + 19 个具体子类），敌人通过 **工厂方法** 创建并配备独立的 AI 行为模式。

## 开发环境搭建

### 前置条件

1. 安装 [Unity Hub](https://unity.com/download)
2. 安装 **Unity 2022.3.62f3c1**（通过 Unity Hub → Installs → Add → 2022.3.62f3c1）
3. 安装模块：Universal Render Pipeline、Windows Build Support、TextMesh Pro（通常随 Unity 自带）

### 克隆仓库

```bash
git clone https://gitee.com/mengge237/distortion-knight-development.git
```

### 打开项目

1. 启动 Unity Hub
2. 点击 **Add project from disk**
3. 选择仓库根目录（包含 `Assets/`、`Library/` 等文件夹的目录）
4. 等待 Unity 完成首次导入（Library 已包含则速度较快）
5. 打开场景：`Assets/_Project/Scenes/MainScene.unity`

### 第三方依赖

| 插件 | 路径 | 说明 |
|------|------|------|
| DOTween | `Assets/Plugins/Demigiant/DOTween/` | 动画补间库，已包含在仓库中 |
| TextMesh Pro | `Assets/TextMesh Pro/` | UI 文本渲染，Unity 内置插件 |

无需额外安装包管理器或导入外部资源。

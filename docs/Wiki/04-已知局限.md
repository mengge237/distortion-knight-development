## 一、空实现列表

### 1. ExhaustCardEffect（卡牌消耗效果）

**文件**：`Assets/_Project/Scripts/Effects/ExhaustCardEffect.cs`

**现状**：`Execute()` 方法体几乎为空，只有注释说明"标记为已消耗，在 HandManager 中特殊处理"。

## 三、资源错放

### TextMesh Pro/Resources 下混入项目资产

**路径**：`Assets/TextMesh Pro/Resources/`

**现状**：TMP 插件的 Resources 目录下混入了以下项目资产：

| 子目录 | 内容 | 应移至 |
|--------|------|--------|
| `BattleBackgrounds/` | 战斗背景图片 | `Assets/_Project/Art/Environment/BattleBackgrounds/` |
| `CardArt/` | 卡牌插画 | `Assets/_Project/Art/UI/Card/` |
| `Effects/` | 效果图标 | `Assets/_Project/Art/UI/Icons/` |
| `EnemySprites/` | 敌人精灵图 | `Assets/_Project/Art/Characters/Enemies/` |
| `NodeBlueprints/` | 节点蓝图 SO | `Assets/_Project/Prefabs/Map/` 或 `Assets/ScriptableObjects/` |
| `PlayerSprites/` | 玩家精灵图 | `Assets/_Project/Art/Characters/Player/` |
| `ScriptableObjects/` | 项目 SO 配置 | `Assets/ScriptableObjects/` |

**影响**：
- TMP 更新时可能覆盖或删除项目资产
- 项目结构不清晰，新成员难以定位资源
- 可能影响构建包体大小（Resources 全量打包）

**计划**：将上述目录迁移到 `_Project/Art/` 对应子目录中，并更新代码中的 `Resources.Load()` 路径。

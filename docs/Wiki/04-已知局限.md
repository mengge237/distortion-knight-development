# 已知局限

> 最后更新：2026-08-15
> 本文档记录当前代码中已知的空实现、硬编码问题和资源错放，供后续开发参考。

## 一、已解决（2026-08-15 归档）

### 1. 硬编码 ID / 路径

**解决方式**：新增 `Assets/_Project/Scripts/Config/GameIds.cs`——`RelicIds`（50 个遗物 ID）、`EffectIds`（2 个固有效果 ID）、`ResourcePaths`（13 个资源路径）三类常量；全项目 23 处 `Resources.Load` 路径、18 处 `hiddenActivatorRelicId`、50 处 `relicId` 改用常量引用，`HasRelic("字面量")` 全部消除。

### 2. 资源错放（TextMesh Pro/Resources 下混入项目资产）

**解决方式**：项目资产已迁移至 `Assets/_Project/Resources/`（Cards / Effects / InherentEffects / Relics / RelicsArt / Potions / EnemySprites / MapTextures / NodeBlueprints / PlayerSprites 等）。

### 3. 文件编码混乱（GBK/BOM 混用）

**解决方式**：全项目统一 UTF-8 无 BOM（修复 1 个 GB18030 + 280 个 BOM 文件），新增 `.editorconfig`（`charset = utf-8`）防回归，校验工具 `Porting/normalize_encoding.py` 入库。

### 4. 商店系统未实现

**解决方式**：商店完整实现（商品生成、购买、打折、补货符、卡牌移除真实选择弹窗、杀戮尖塔式布局），见 `ShopDataService` / `ShopPanel`。

### 5. 遗物合成配方失效

**解决方式**：剑刃碎片 + 剑柄碎片 → 剑之核心配方原为死值（"01"/"06"），已改为 `RelicIds` 常量引用（`RelicMergeService.cs`）。

### 6. 卡牌移除逻辑为假实现

**解决方式**：原"移除牌组第一张"改为运行时选择弹窗，选中卡牌确认后扣款移除（`ShopPanel.OpenCardRemovalDialog`）。
